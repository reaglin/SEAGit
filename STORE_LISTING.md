## App name

SEAGit

## Description

> SEAGit publishes a folder on your computer straight to GitHub in one click —
> no branching, staging, or command-line knowledge required.
>
> Powered by **Git (included)** — Git for Windows is bundled inside SEAGit;
> no separate install is required.
>
> SEAGit is a desktop app for non-technical users who want to back up a folder
> to GitHub or share it as a website, without learning Git.
>
> How it works:
> • Pick a folder on your PC.
> • Paste your empty GitHub repository URL the first time.
> • Click Publish. SEAGit stages, commits, and pushes everything for you.
> • The next time you change anything in the folder, click Publish again.
>
> What's bundled:
> • Git for Windows (MinGit) is included inside the app. You don't need to
>   install Git separately.
> • Git Credential Manager (also bundled) handles the GitHub sign-in via your
>   browser; SEAGit never stores your GitHub password or token.
>
> Your tracked-folder list is saved on your PC only. SEAGit collects no
> analytics and requires no SEAGit account.

## Short description

> One-click "Publish to GitHub" for a folder on your PC. SEAGit bundles Git
> for Windows inside the app, so non-technical users can back up or share a
> folder on GitHub with no Git install, no branching, and no command line.

## Product features

Optional bullet list shown on the Store page (separate from the Description).

- Publish a local folder to GitHub in one click
- Bundles Git for Windows (MinGit) — no separate Git install required
- Browser-based GitHub sign-in via the bundled Git Credential Manager
- Tracks multiple folders and shows when each was last published
- Initializes a Git repository for you on first use
- No account, no telemetry — your folder list stays on your PC
